HTML Structure
<!DOCTYPE html>


Declares the document type as HTML5. Browsers know to interpret it as modern HTML.

<html lang="en">


Opens the HTML document.

lang="en" specifies the language for accessibility and SEO.

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">


<meta charset="UTF-8">: Ensures text uses UTF-8 encoding, supporting almost all characters.

<meta name="viewport"...>: Makes the website responsive, adjusting layout to mobile and desktop screens.

  <title>Your Name - Interactive Resume</title>


Sets the title of the page (shown in browser tab).

  <script src="https://cdn.tailwindcss.com"></script>


Imports Tailwind CSS, a utility-first CSS framework for styling.

This lets you write classes like bg-blue-600 or text-center without creating a separate CSS file.

Custom CSS
  <style>
    html {
      scroll-behavior: smooth;
    }


Makes scrolling between sections smooth instead of jumping instantly.

    .skill-bar {
      width: 0;
      height: 1rem;
      background-color: #3b82f6;
      border-radius: 0.5rem;
      transition: width 1.5s ease-in-out;
    }
  </style>


Defines the skill bars animation:

width: 0; → starts at 0, will grow with JS

height: 1rem; → bar height

background-color: #3b82f6; → Tailwind blue color

border-radius: 0.5rem; → rounded ends

transition: width 1.5s ease-in-out; → animates width smoothly

JavaScript for Skill Animation
<script>
  const skillBars = document.querySelectorAll('.skill-bar');

  window.addEventListener('scroll', () => {
    skillBars.forEach(bar => {
      const rect = bar.getBoundingClientRect();
      if (rect.top < window.innerHeight) {
        bar.style.width = bar.dataset.width;
      }
    });
  });
</script>


Selects all .skill-bar elements

On scroll, checks if bar is visible in viewport
